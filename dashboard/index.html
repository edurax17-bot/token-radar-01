    How implied value is computed

    One function scores every row, from the snapshot's own figures only. No protocol name is special-cased and no row is hand-picked.

    • Multiple. The median market-cap-to-TVL ratio of the snapshot's own token protocols (exchanges excluded), measured at run time — the market's own answer to what a dollar of TVL is worth as a token.
    • Growth. Seven-day TVL change, clamped to −40%…+80%, moves the value by up to ±48%: a protocol gaining users is worth more than one shrinking at the same size.
    • Maturity. Days since first listing, capped at four years: the longer a protocol has run with no token, the more established its record — up to +25%.
    • Breadth. Each extra chain, up to four, adds 3%: a protocol live in more places reaches more farmers.
    • Separation. Protocols whose token already trades never enter the ranking; the biggest 24 by market cap are listed separately below, with their market caps, so the reader can compare a model's claim with the market's own prices.

    Live tokens, set aside

    These protocols already trade. Their market cap is a fact, not a model, so they are not ranked — they are the yardstick the multiple is measured from.
